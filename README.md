# Wireshark Network Traffic Analysis

## Project Overview

This project focuses on capturing and analyzing live network traffic using Wireshark on a personal network.

## Objectives

- Capture live network packets.
- Identify network protocols.
- Analyze DNS queries and responses.
- Review communicating hosts and endpoint statistics.
- Document observations and potential anomalies.

## Tools Used

- Wireshark
- Personal computer
- Personal home network
- Web browser

## Methodology

1. Select the active Wi-Fi or Ethernet interface.
2. Capture network traffic while browsing websites for 2–3 minutes.
3. Stop the capture and save it in `.pcapng` format.
4. Analyze protocol distribution using Protocol Hierarchy.
5. Inspect DNS traffic using the `dns` display filter.
6. Review Statistics → Endpoints.
7. Record findings based on the actual capture.
